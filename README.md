# NetworkTelemetryApp

NetworkTelemetryApp is a component of a larger network monitoring project developed as part of an academic project. While the complete system is maintained in a separate repository, this project contains the core engine responsible for network analysis, from discovering devices to identifying potential security threats.

## Overview

This application serves as the **anomaly detection engine** of a larger network monitoring system. It is responsible for the entire process of gathering network information, monitoring traffic, and identifying unusual or potentially dangerous activity.

Its primary goal is to detect network anomalies and potential security threats by analyzing connected devices and network traffic.

## Features

- **Network Scanning** — Discover devices connected to the network and gather information about them.
- **Network Traffic Monitoring** — Capture and analyze network traffic to identify unusual patterns and suspicious activity.
- **Anomaly Detection** — Analyze network activity to identify irregularities that may indicate potential security threats.
- **Threat Identification** — Detect potentially dangerous behavior and suspicious network activity.

## Role in the Larger Project

NetworkTelemetryApp is part of a larger project that integrates multiple components into a network monitoring system.

This repository focuses on the **core network analysis and anomaly detection engine**, handling the entire process from network discovery to potential threat identification.
